# Tables

The section heading keeps **bold**, *italic*, `code`, and ~~strike~~ visible above the grids.
A GFM table renders as a bordered grid with a header row and body rows.
The pipe-and-dash source stays in the document but hides while the caret is outside the table.
Several tables on one page each keep their own header and cells.
Column headers keep **bold**, *italic*, and `code` like body cells.
Inline **bold**, *italic*, and `code` inside a cell still format in the grid.
