# Tables

The section heading keeps **bold**, *italic*, `code`, and ~~strike~~ visible above the grids.
A GFM table renders as a pipe grid on top of its source lines.
Each source row keeps its line number.
A short row stays one editor line tall.
A wrapped cell grows that row only.
The pipe-and-dash source stays in the document and is covered while the caret is outside the table.
Several tables on one page each keep their own header and cells.
Column headers keep **bold**, *italic*, and `code` like body cells.
Inline **bold**, *italic*, and `code` inside a cell still format in the grid.
