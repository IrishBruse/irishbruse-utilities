# HTML blocks

Inactive HTML blocks render as a preview. Click to edit the raw HTML.

## Simple block

<div class="note">
  <strong>Note:</strong> HTML preview for inactive blocks.
</div>

## Nested elements

<section>
  <h3>Section title in HTML</h3>
  <p>Paragraph with <em>emphasis</em> and a <a href="https://example.com">link</a>.</p>
  <ul>
    <li>One</li>
    <li>Two</li>
  </ul>
</section>

## Inline HTML in a paragraph

You can use <kbd>Ctrl</kbd>+<kbd>S</kbd> and tags like <span style="color: #61afef">colored span</span> mid-sentence.

## Self-closing and voids

<br>
<hr>
<img alt="placeholder" width="1" height="1">

## Mixed with Markdown

Before the HTML block.

<details>
  <summary>Expand me</summary>
  <p>Hidden details content.</p>
</details>

After the HTML block.
