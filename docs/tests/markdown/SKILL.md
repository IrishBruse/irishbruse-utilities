# SKILL.md properties fixture

Open this file with **Reopen Editor With... → Markdown Editor (ib-utilities)**. The YAML front matter should paint as a **PROPERTIES** card, not a raw YAML block.

Checklist:

1. Header shows **PROPERTIES** and the field count.
2. Edit `name` and `description`; swap to the text editor and confirm the YAML updated.
3. Toggle `disable-model-invocation`.
4. Use **Add property** and pick `compatibility` from the list (Tab or Enter).
5. Collapse the card with the chevron; expand it again.
