# Basic text

The main heading is larger than the section heading.
The section heading is larger than the smaller heading.
The heading words stay visible.
The hash marks stay hidden.

A bold word is heavier than the words beside it.
The asterisks stay hidden.
The word lines up with the bold mark.

An italic word slants.
The asterisk stays hidden.
The word lines up with the italic mark.

A struck word is crossed out.
The tildes stay hidden.
The word lines up with the strike mark.

A coded word uses a code face.
The backticks stay hidden.
The word lines up with the code mark.

A link label is colored.
The address stays hidden.
The label lines up with the link mark.
