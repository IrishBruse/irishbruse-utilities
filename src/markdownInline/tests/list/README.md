# Lists

A list shows a bullet beside each item.
The bullet sits on the same column as the raw `-`, outside the line-number gutter, and the label starts after it.
A nested item keeps its own bullet, set in from the parent.
The words line up with that bullet.
A numbered list keeps its numbers visible.
A task item shows a checkbox with clear space before its label, not a list bullet.
