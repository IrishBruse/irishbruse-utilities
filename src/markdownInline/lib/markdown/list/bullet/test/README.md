# Bullets

A list shows a bullet beside each item.
The bullet sits on the same column as the raw `-`, outside the line-number gutter, and the typed space after `-` is the gap before the label.
A caret on the dash or right after it shows the raw `-`.
A nested item keeps its own bullet, set in from the parent.
The words line up with that bullet.
A continuation line under a list item uses the same editor text color as the first line of the item.
